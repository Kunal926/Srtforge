# tasks/

Per-task notes for small (~1 hour) work. Use `../TASK_TEMPLATE.md` as the
starting point. For larger or cross-cutting work, write an ExecPlan in
`../exec-plans/active/` instead — see `../PLANS.md`.

Naming: `<verb-slug>.md`, e.g. `wire-progress-events.md`,
`fix-zombie-worker-shutdown.md`.

Lifecycle: keep notes around for ~1 release after the task lands, then
delete or roll into ADRs / `QUALITY.md` if there's anything durable.
